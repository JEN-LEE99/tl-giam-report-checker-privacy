TL Giam AI Report Checker – Privacy Policy

Last updated: September 2026

TL Giam AI Report Checker is designed to assist authorised TL GIAM users reviewing motor claims in the Merimen claims system.

Information processed by the extension

The extension reads claim, report and estimate information displayed within Merimen in order to perform validation checks and display results to the user. Processing is performed locally in the browser.

The extension may read the email address associated with the current browser profile solely to determine whether it belongs to the tlga.com.my company domain.

The browser profile email address is not stored or transmitted by the extension. Users whose browser profile cannot be verified may activate the extension using a separate activation code.

Merimen authentication information

Merimen authentication and session information may be read temporarily when required to make same-origin requests to Merimen.

Authentication information is not stored in the extension's claim cache and is not transmitted to any third-party service.

Local storage and caching

Claim and report information may be temporarily cached using chrome.storage.session to support validation across Merimen pages.

This cache is session-scoped and is cleared when the Merimen logout flow is detected. It does not persist as permanent claim storage.

chrome.storage.local is used only for extension preferences and the local activation state.

Claim and report information is not stored in chrome.storage.local.

Data sharing

The extension does not operate a backend server, does not sell user data, does not use claim data for advertising, and does not transmit claim information to external analytics or third-party services.

User data is used only to provide the extension's stated claim-review and validation functionality.

Data retention

Temporary claim data is retained only for the active browser session as required for the extension to operate across Merimen pages.

Local activation state and user preferences may remain stored until the extension is removed or its extension storage is cleared.

User control

Users can remove locally stored extension data by uninstalling the extension or clearing the extension's local storage.

Logging out of Merimen clears the extension's session-based claim cache.

Chrome Web Store User Data Policy

The use of information handled by TL Giam AI Report Checker adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Changes to this policy

This privacy policy may be updated if the extension's functionality or data-handling practices change.
